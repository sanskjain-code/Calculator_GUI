# 🧮 Calculator GUI

A simple Calculator application built using **Python Tkinter**.  
This project demonstrates the basics of GUI development in Python with clean layout and interactive buttons.

---

## 🚀 Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Clear button to reset input
- User-friendly Tkinter interface
- Lightweight and beginner-friendly project
